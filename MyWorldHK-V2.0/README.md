# 🏙️ 香港中环 · 我的世界（蓝图复刻版）

> 一个用「对话 + 图纸」敲出来的体素城市沙盒 · VibeCoding 作品

一个基于 Three.js 的单文件体素（Voxel）沙盒。**不需要安装、不需要构建，双击即玩**——在浏览器里走进香港中环，亲手复刻、也能亲手拆改两座世界级地标。

---

## ✨ 这是什么

- 🏢 **按建筑图纸复刻的中银大厦**——贝聿铭的「节节高升」：底部满正方形，向上**四段收分**（逐段削去三角柱体），顶冠双桅杆；立面为银蓝玻璃幕墙 + 白色铝框**菱形斜撑网格**
- 🏗️ **汇丰总行大厦**——诺曼·福斯特的高技派：**8 组外露铝包钢柱**、5 道三角悬挂桁架、底层架空可穿行、平顶直升机坪，并保留楼顶那台标志性的**「炮筒」形清洁玻璃装置**
- 🌆 **中环街景**——德辅道中、毕打街、皇后大道、花园道、皇后像广场（雕像与树）、双层叮叮车、维港水面
- ⛏️ **我的世界玩法**——WASD 行走、空格跳跃、F 飞行、左键拆除、右键放置、1~9 切换方块
- 📦 **自包含**——单 HTML 文件，CDN 加载 Three.js，双击或一键部署

## 🎯 我为什么做这个

起点只是一句「想做一个我的世界」。后来和 AI 聊着聊着，地形长出来了、街区长出来了；再后来，我把几张中银大厦的建筑图纸丢给它，问了一句：

> 「能不能照着这个，把塔的收分和斜撑做对？」

于是就有了这个版本——**轮廓是从图纸上一段段量出来的，不是凭印象捏的**。

这大概就是我理解的 **VibeCoding**：没有冗长的规格文档，凭一个念头、几张图、一轮轮对话，把想法推到「真的能跑、真的像」。过程开心，结果看得见。

## 📐 图纸驱动：中银大厦是怎么被「量」出来的

项目目录里的图纸正是这次重构的依据：

| 图纸 | 提取到的信息 |
|---|---|
| `中银大厦主视图纸.png` | 平面序列：满正方形 → 削去东北角 → 西南直角三角形 → 等腰三角尖顶 |
| `中银大厦侧视图纸.png` | 楼层与机电层标高：70 层封顶、双桅杆 |
| `中银大厦.png` | 立面 X 形斜撑拼成的菱形网格、下宽上窄的阶梯轮廓 |
| `立体结构概念图.png` | 三段渐进收缩与柱廊基座 |

据此实现的四段收分（体素格，1 格 ≈ 4.3 米）：

```text
第 1 段   y 3  – 25   满正方形（13 × 13）
第 2 段   y 26 – 38   削去东北角三角形
第 3 段   y 39 – 51   西南直角三角形
第 4 段   y 52 – 71   等腰三角窄尖
顶冠      y 72        白色压顶
双桅杆    y 73 – 85   主桅 + 副桅（约 52 米），总高约 366 米
```

> 轮廓是否正确，可以直接跑校验收尾输出的 ASCII 侧视剖面图，与图纸逐层比对。

## 🧱 技术要点

- **体素引擎**：Uint8Array 扁平网格 + 合并 BufferGeometry + 面剔除（只渲染暴露面）
- **零素材**：所有方块贴图由 Canvas **程序化生成**，无任何图片依赖
- **立面程序化**：斜撑按 (u ± y) % 11 生成 X 形对角线，角部竖铝条、机电层横带自动判定
- **几何判定**：inBOC(x, z, y) 用四段不等式描述建筑轮廓，收分处的削角是纯数学结果
- **自写物理**：AABB 碰撞、重力与跳跃、体素射线拾取（步进采样）
