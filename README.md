# 🏙️ 我的世界 · 香港中环体素沙盒

> **VibeCoding 作品 · 一个凭"感觉 + 对话"敲出来的体素城市**

![](./preview.gif)

香港中环，两座世界级地标，一整个可拆可建的方块城市——用浏览器就能玩，双击打开即体验。这是我和 AI 结对、"边聊边做"敲出来的一个开源小玩具。

---

## ✨ 这是什么

一个基于 Three.js 的体素（Voxel）城市沙盒。不需要安装，不需要构建，一个 HTML 文件，双击即可进入：

- 🏢 **复刻现实地标**——贝聿铭的**中银大厦**（四棱三角柱体、东侧最高带双桅杆、玻璃+铝条），福斯特的**汇丰总行**（高技派外骨骼钢柱、底层架空、平顶直升机坪、楼顶"炮筒"清洁装置）
- 🌆 **香港中环街景**——德辅道中、毕打街、皇后像广场、双层叮叮车、维港水面
- ⛏️ **我的世界玩法**——WASD 移动、空格跳、左键拆、右键建、1~9 切方块，改造你的城市
- 🎮 **自包含**——单文件、CDN 加载 Three.js，双击即玩、也可一键部署

---

## 🎯 我为什么做这个

最初只是"想做一个我的世界"，后来却越聊越上头——AI 随口建议"不如把开头地点放在香港中环吧"，于是两座建筑、叮叮车、维港就一样一样长了出来。**项目是聊出来的，是我和 AI 一起把想象敲成现实的记录。**

> 对我而言，这就是 **VibeCoding**：没有严格的规格，凭一种"我想要它存在"的感觉，和 AI 不断对话、试错、打磨，最后收获一个**能跑起来、能看到、能玩到**的成果。

它不炫技，但每一步都真实发生、真实可见。

---

## 🧱 技术栈

- **Three.js** —— 3D 渲染 / 体素网格合并 / 面剔除
- **Canvas 程序化纹理** —— 无任何图片素材，全部方块贴图由代码现场生成
- **纯 JavaScript** —— 无框架、无构建、单文件自包含
- **体素物理** —— 自写 AABB 碰撞、重力、方块拾取

## 🎮 操作指南

| 操作 | 按键 |
|---|---|
| 移动 | `W A S D` |
| 跳跃 / 飞行（切） | `空格` / `F` |
| 拆除 / 放置方块 | 鼠标左键 / 右键 |
| 切换方块 | `1~9` 或滚轮 |
| 释放鼠标 | `Esc` |

## 🗺️ 世界一瞥

- **中银大厦**：13×13 格基座，四组三角柱体自西向东阶梯上升（20→40→59→79 格），东侧双桅杆直指 368 米
- **汇丰总行**：18×14 格体量、底层 8 米架空可穿行、8 组外露银柱、5 道三角桁架、平顶直升机坪 + 楼顶"炮筒"清洁装置
- **皇后像广场**：雕像、树、绿荫，开局正前方就是中银与汇丰的"建筑对话"
